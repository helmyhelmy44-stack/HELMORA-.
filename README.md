# ProShot 📷

## احتراف الكاميرا. ذكاء يفهم اللقطة.

ProShot هو تطبيق كاميرا احترافية للهواتف، مصمم للجمع بين قوة أدوات التصوير الاحترافية وسهولة الاستخدام والذكاء المساعد للمصور.

---

## رؤية المشروع

نريد بناء كاميرا لا تكون مجرد تطبيق لالتقاط الصور.

ProShot سيكون:

- كاميرا احترافية
- مساعد تصوير ذكي
- كاميرا فيديو احترافية
- نظام تصوير ليلي متقدم
- نظام تحكم يدوي
- دعم RAW عندما يسمح الجهاز
- محلل للقطات
- مساعد للتكوين
- استوديو لتحرير الصور
- نظام ملفات تعريف للإعدادات
- نظام توافق ذكي مع قدرات الهاتف

---

## الفلسفة

### المصور هو صاحب القرار

الذكاء الاصطناعي لا يستبدل المصور.

دور ProShot هو:

فهم المشهد → اكتشاف المشكلة → اقتراح الحل → ترك القرار للمصور.

---

## أهم ما يميز ProShot

### Photographer's Eye

ميزة ذكية تساعد المصور على فهم سبب اختيار الإعدادات، وليس مجرد عرض أرقام.

مثال:

ISO 400

بدل أن نعرض الرقم فقط:

> تم اقتراح ISO 400 لأن الإضاءة منخفضة مع محاولة الحفاظ على سرعة غالق مناسبة.
