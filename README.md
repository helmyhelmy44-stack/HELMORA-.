# HELMORA 📷

## عين ترى أكثر.

HELMORA هو تطبيق كاميرا احترافي للهواتف، يجمع بين قوة أدوات التصوير الاحترافية والذكاء المساعد للمصور.

> لا نلتقط الصورة فقط... نساعدك على رؤيتها.

## الرؤية

HELMORA ليس مجرد تطبيق كاميرا.

إنه منظومة تصوير تجمع بين:

- كاميرا احترافية
- تحكم يدوي
- تصوير فوتوغرافي متقدم
- تصوير فيديو احترافي
- ذكاء لتحليل المشهد
- مساعد للتكوين
- دعم RAW عندما يسمح الجهاز
- تحليل الصور
- استوديو لتحرير الصور

## المبدأ

المصور هو صاحب القرار.

الذكاء يساعده ولا يستبدله.
